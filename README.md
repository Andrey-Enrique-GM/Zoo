# Zoo Project 🦥
Este proyecto sirve para administrar un *zóologico*.

## Instalación
Para montar este proyecto instala las dependencias del archivo **requirements.txt** usando el siguiente comando:

`pip install -r requirements.txt`

## Agregar chihuahuas
En la página principal, pulsa **Agregar un Chihuahua** y completa el tipo, la descripción y la ruta de una imagen existente dentro de `static` (por ejemplo, `images/chihuahua_manzana.png`). Al guardar, el registro aparece en la tabla y queda almacenado en MySQL; Docker Compose conserva los datos en `mysql_data`.
